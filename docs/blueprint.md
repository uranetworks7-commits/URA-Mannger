# **App Name**: X Crypto Accounts

## Core Features:

- Account Creation (X Post): Create a new X Post account with username, chat name, and avatar URL. Stores data in Firebase (emulated), structuring user data under a unique ID within the 'users' node.
- Account Creation (Bitcoin): Create a Bitcoin-related account, storing the chat name and account name. The user gets automatically credited a small amount of bitcoin (.00014038443406577932) in a Firebase emulated database, in a data structure described below.
- Account UI: Clean interface to create and manage user accounts. On launch displays the 'URA System' landing screen, and has buttons for different account types.

## Style Guidelines:

- Primary color: Slate blue (#7395AE), chosen for its association with technology and trust, aligning with the account creation aspect.
- Background color: Very light gray (#F0F4F8), providing a clean and modern backdrop.
- Accent color: Pale gold (#D4A373), used to highlight interactive elements and calls to action, creating a subtle contrast.
- Font: 'Inter', a grotesque-style sans-serif chosen for its modern and neutral appearance, suitable for both headlines and body text. Note: currently only Google Fonts are supported.
- Use minimalist icons to represent account types and actions.
- Design a clean, intuitive layout for account creation forms.
- Incorporate subtle animations for a modern user experience when creating accounts or loading data.
